# 《窄门》Owen × Maggie 工作盘

> 配角工作档（Owen 与 Maggie 合档）。本档为独立工作盘，未入权威档；世界真相仍以《窄门_Jack与Jacob_设定档.md》为准。等"入档/拍板"指令后，第七节冲击清单里的条目再同步。
> 背景：Owen 情敌线为原作者钦点方向（"感觉您构思这类白男的设定会很出彩"），本盘按此推进。

---

## 〇、定位总纲

**两人是一套"对照组设备"，各照一个主角：**

- **Owen 照 Jack**：穷得自由 vs 富得锁死。Jack 输光后没有可失去的了（门没开，他早住在门的另一边）；Owen 赢了全部，代价是终身深柜。Jack 的贫穷是他仅剩的自由，Owen 的财富是他唯一的牢房。
- **Maggie 照 Jacobo**：半途而废引擎的羞愧版 vs 安宁版。Jacobo 摆烂伴随愧疚与复学；Maggie 摆烂伴随彻底的宁静——她从没点燃过任何东西，所以永远不需要第四次熄火。

**两条铁纪律：**

1. **Owen 这朵桃花必须是 Jack 惹出来的**，不能是 Owen 自己找上门。因果链前段（入职→发光→重逢→赴约）每一环都是 Jack 自己走的。
2. **Owen 追求期绝不碰杠杆**：手里握着 Jacobo 的董事会，而他在追 Jacobo 的人——全程不用。干净是他相对 Jacobo 的唯一结构性优势，也是他的承重墙。

**质感基调：美式情景喜剧。**A 线（工作）顺滑，B 线（感情）雷区。Owen 的每个阴招都走同一条流水线：书房+威士忌+军事推演 → Maggie 沙发上拆台 → 凌晨删稿 → 次日董事会对 Jacobo 格外和蔼（愧疚补偿）。

## 一、Owen 档案

### 1. 基本盘
- Jack 的 UCB 校友，**点头之交**；与 Jack **没有旧情**。
- 真·白人老钱大家族继承人，深柜（家族压力），抗拒家族。
- **Gay Top**——体位≠权力：他是 top，却被家族按得死死的。全书语法里的倒挂款。
- Jacobo 的**投资人**：Jacobo 为不让 Californios 本家插手，引入外部资本，Owen 的老钱家办入局。Owen 全知昼场 Jacob，是 Jacobo 的钱、命、昼场天花板。

### 2. 白月光机制
- 他憧憬的是**高光栏里的 Jack**（USACO Gold、Cal Hacks 队长），没见过断崖后的成色。
- 爱的仍是展签不是展品：真追到手，面对情绪表达最高到"哦"的丧气 Jack，白月光撑不过一个季度。
- 对偶：Jacobo 捡到的是烂尾工程，越修越上头。一个爱高光栏，一个爱烂尾楼——报价单 Jack 用脚投票。

### 3. 求爱语法：明确上下级
- 一切安排：餐厅、节奏、条款、未来文件夹。Jack 唯一的岗位职责是"到场并接受"。
- 这完美地迎合 Jack 最烂的本能（不主动不拒绝不命名），所以是**警报不是福利**——"什么都不用做"就是工位描述。
- 老钱家族语言 = 安排、中间人、条款（**WASP 版静音执法**）。他的悲剧是不自知："我只是周到。"
- 与 Jacobo 的对照（Jack 的情感二分法）：
  - **Owen = 零悬念**，固定存款，金漆聘用合同；求爱只问一次（在文件夹里），然后期待永久生效。
  - **Jacobo = 变量奖励**，老虎机；情趣层有安全词，生活层凡事可商量——每次"商量"都是一次日常同意续签。
  - Owen 给的是"被驾驶"，Jacobo 给的是"旁边坐着个嘴很坏但不替他打方向的人"。

### 4. 出场因果链（Jack 惹出来的）
1. Jack 入职 Jacobo 公司（**Rachel 招的**，不是 Jacobo、不是 Owen）——自主选择；
2. 公司危机，Jack 当着董事会把火灭了——能力公开展示；
3. Owen 坐在投资人席，看着存档八年的白月光重新发光——白月光解冻；
4. Owen 以"校友+被投公司社交"名义发出第一顿午饭——可否认、合规矩，但若 Jack 没走进视野，这顿饭不存在；
5. **Jack 赴约。又赴约。再赴约**——Jacobo 逃避期的回血（详见第五节时间线）；
6. Owen 尽调"我们创始人怎么在发光"→ 风控报告落地 → Jacob 和 Jack 的纠缠浮出水面 → 重算"直男？可开采？"→ 升级追求；
7. 形婚+代孕 offer → 被拒 → 同归于尽（Rachel 空降）。

**一次逃避 = 一顿午饭。**桃花有计量单位。

### 5. Jack 对 Owen 的未付账（明写）
- Jack 赴约的动机从来不是暧昧：Jacobo 给他碰壁时，Owen 是他唯一能说上话的**平级**。
- Jack 的循环：Jacobo 让他碰壁 → 他去 Owen 那里回血 → 回完血再回去撞墙。
- 他最狠的认罪词（拒绝那场戏用）："我不是不知道。我只是……装不知道。"
- 全剧最疼的喜剧结构：**Jack 跟 Owen 吐槽 Jacobo，而 Owen 是全桌唯一知道他俩什么关系、还知道自己正在追吐槽对象的人。**Owen 当场收下每颗弹药、当场不装填。

### 6. 形婚 + 代孕 offer
- 美式深柜全套解决方案：婚姻主体 + 代孕 KPI（生物指标）+ 债务清偿 + 体面邮编。尽调完备的基础设施方案，专钓"机构入住" wiring。
- Jack 的拒法（合同语系拒合同，自主行为之一）："**违约金太高了。**"推开文件夹，走人。
- 可选加一拍（待定，第八节）：指尖停在签字页，"条款挺全的。就是没写他。"
- 配套的 crash：Jacobo 冲进求婚饭局，"今天就让你怀孕。"Jack 拒绝得平静，走得屁颠——**创始人在自己投资人的私人饭局上抢人**，Owen 微笑切牛排，把亏吃成风度，散场对 Maggie 说"牛排不错"。

### 7. 阴招废案：Rachel 空投 CTO（想过，没做）
- 毒辣之处：与良政一模一样。"贵司该请一位成年技术领袖了。"
- 三层自爆推演：
  1. Rachel 不可建模（全书唯一全程没失控过的人；请进来的不是 CTO 是审计）；
  2. 她是**全部账本的交汇点**（Jack 崩溃史亲历 + 西雅图俱乐部见过 Jacobo + 一旦入职三条线在她身上闭合）——想放蜜蜂，结果把真相引信装进自己的被投企业；
  3. 做了这招，他就成了他妈——中间人式施压 = WASP 版静音执法 = 他一辈子在逃的那只手。干净这个优势当场花光。
- 处置：凌晨两点书房删稿，全程无人知晓。**老钱连放弃阴招都要体面。**
- 可选鬼影（第八节）：托猎头口头"随便问问"Rachel；她接到一通来路古怪的电话，没下文，某次闲聊提给 Jack。废招的余波让正规猎头真注意到她——老钱白白给命运交了笔咨询费。

### 8. 同归于尽（实案）：追求失败后，Rachel 空降 CTO
- 时机：输在干净不再有用之后——教养准他打这一发，打完就退场。
- 手法：作为投资人推 CTO 候选人，履历无懈可击，全程可否认。像治理，实质妒火。
- 哑火原理：Rachel 落地九十秒拼完全部拼图，认出"又拿我当弹药"（ begging call 当过一次奖品），**归档、接 offer、宣布置身事外**——弹头自己走出落点。
- 比引爆更狠的是她的"在场"：全知 + 不作为，成为 Jacobo 的直管下属；每周 1:1 与握着全本账的人讨论 OKR。她的唯一警告用职业语系："你公司治理和你私生活一个结构——**杠杆加太满，迟早穿仓。**"
- Owen 至死不知 Jack 要什么（以为他还念 Rachel）。他的惩罚：哑弹永远挂在被投公司的组织架构图上，每周董事会提醒他最后一步棋也下错了。

### 9. Owen 退场后的余味
- Maggie 把 Magic Mike 票根贴冰箱，标注"therapy expenses"，按月找他报销。他每次都付。
- 他永远只知昼场 Jacob，不知夜场 Jacobo——差最后一厘米（自愿的无知，breeding：体面人不往"闯入"上想）。

### 10. 台词弹药库
> "你最近，是有人走了，还是有人没来？"（只问一次，条款记下：自己是气候，不是归宿）
> "我？我只是周到。"（被暗示控制时的震惊）
> "牛排不错。"（求婚局被抢人之后）
> "他说那人口罩戴得比谁都熟练。"（对 Maggie 复述 Jack 的话，说完自己愣住）
> 微观读盘三连：Jack 赴约迟到→自己点菜→自己挑餐厅。每一次自作主张，Owen 都准确读成讣告——第一次点菜那秒他就知道输定了，还坚持吃完了甜点。老钱连死心都吃全套。

## 二、Maggie 档案（干净版）

### 1. 基本盘
- 家族私生女，为体面被接回，假扮 Owen 远房表妹；真名 Maggie（对 Magnolia）。
- 成年前在 Trailer Park 跟着监护人生活。目前除正式场合装装样子，其余时间摆烂混饭。
- 住 Windsor 便宜单元（符合朴素表妹人设；混 = 从不露富）。**是否战略性拖欠房租：第八节待定**（若保留，与 Jack 组成"欠租者同盟"，互交流拖租心得）。

### 2. 核心设定（本次调整：**无创伤、无觉醒**）
- 就是来混的。不恨家族、不嫌家族——龙虾挺好吃的。
- 无法被羞辱：羞辱的前提是她认可对方的评价体系，她一个标点都不认可。
- 照妖镜功能：不主动拆穿——只要在场，虚伪自动显影。全家最锋利的讽刺是一个毫不在场的人。
- 她是**主要角色里唯一的无伤口成年人**：动机纯正得像一张发票（来混的）。病灶单一性/人感纪律全员受益。

### 3. 职业技能：拖车公园雷达
- 识人是**手艺不是智慧**——跟锁匠认锁一个道理。闻得出假资历、假身份、假笑。
- 与 Jacobo 的同行评审：真相边缘化时不说"我懂你"，说"**哥们儿，手艺不错。**"
- 假名行业协会驻 Windsor 办事处：Owen 造假证件，Maggie 本人就是一张假证件，Jacobo 伪造了一个角色——她任监事。
- 对秘密的态度："哦，咸的。"——不接任何重量。

### 4. 对 Jacobo：活体证据
- 她是"半途而废也不一定会毁掉人生"的活体证据，且零自觉。对一个靠羞愧运转的引擎来说，遇见毫无羞愧的同行，比任何说教都晃。
- 楼的第一发现者：Jacobo 衰败期"楼怎么又破了"由她点破；嫉妒基础设施期（楼宇维护全面提升）也是她第一个起疑"这楼怎么突然不破了"。

### 5. 与 Rachel：浅得刚刚好的友谊（全书最健康的关系）
- 周三周五 Magic Mike 固定场，**永不讨论那三个男人**。
- Rachel 的置身事外是老兵纪律；Maggie 的置身事外是天生的（一辈子 civilian）。
- 健康的原因反直觉：**因为浅**——不聊创伤、不问进展。Rachel 在她身边不用当"处理得当的 Rachel"，可以只当观众。B 线的电影院，不是诊室。
- 可选：Rachel 的未婚夫在 Magic Mike 之夜认识（婚礼单元出处的候选）。

### 6. 功能件
- **读者席位**：全场唯一的观众。任何戏张力过载，切她一个吃瓜镜头就泄压。玻璃渣糖厂里递勺子的人。
- **跑团任意门**：不升级冲突、不接告白、不背秘密重量，任何场景塞进来都更好玩不会更危险——agent 最好用的减压阀。

## 三、Owen × Maggie 共犯结构

1. **业务关系（纯业务，服务标准极高）**：他给她造假资历和财产证明 + 挡家里的刀；她挡他的催婚和相亲。按年续约。她把这差事干得漂亮不是出于忠诚，是出于**职业混子的职业操守**——活简单、管饱、不用动脑，这种岗位值得最高标准维护。Owen 这辈子用钱买到的所有忠诚里只有这份是真的。
2. **情报站**：Maggie 两头卖。把"有人要抢你房租先生"卖给 Jacobo，报价一月房租——Jacobo 全书第一次为别人付的信息费，付完自己先烦（又超剧本了）。反手可能把 Owen 的相亲动向卖给 Jack 换人情。
3. **阴招流水线**（B 线拍法）：书房+威士忌+军事推演 → Maggie 沙发上吃着他的零食拆台 → 凌晨删稿 → 次日董事会对 Jacobo 格外和蔼。
4. **Maggie 拆台台词库**：
   > "哥，你管这个叫 CTO 招聘？你这是在人家客厅里放蜜蜂。"
   > "你要真发了这封邮件，我以后就不帮你挡相亲了——因为你也配不上了。"
   > "你那是想睡他还是想救他？分不清就别动，显得 cheap。"
5. 家族晚宴戏：两边各自演得体面，Owen 桌下被母亲催婚，Maggie 在自助餐台真诚做自己，全家必须表演疼爱她。散场车库分钱，一句谢谢都没有。

| 关系 | Owen 知道 | 对方知道 |
|---|---|---|
| Owen → Jacobo | 全知昼场（投资人/董事会） | Jacobo 知道 Owen 在追 Jack（Maggie 卖的），且 Owen 是他的钱、命、昼场天花板 |
| Owen → Jack | 大学点头之交 + 白月光（不知断崖成色，后知道） | Jack 不知 Owen 是 gay、不知 Owen 是投资人（建议保持到 demo day 当场发现，A 版） |

## 五、时间线槽位（中段为主）

1. **中段**：Jack 被裁（现公司试用期第二轮裁员，时代灰尘替他辞职）→ Rachel 招募进 Jacobo 公司 → 第一场四人危机 → demo day / 董事会，Jack 发光，Owen 白月光解冻。**建议 A 版：Jack 入职前不知 Owen 是投资人**，台上扫码看到投资人席瞳孔地震，还必须把方案讲到满分。
2. **Jacobo 逃避期**（夜场衰减 + 回游测试名字枪杀后 + 摊牌摇摆）：Jacobo 在家排练诚实，Jack 在外头体验被抛弃。Jack 三级碰壁：
   - 行政级（首撞）：报修单——"那晚之后我的锁不安全，换锁，调监控。"Jacobo 收到自己作案现场的售后工单，连夜删自己，delegated 给物业大爷；
   - 社交级：补谢维修的饭（callback 报修夜起源），Jacobo"出差"；
   - 直球级：Jack 问"你是不是知道那晚的人是谁？"——太准，Jacobo 死机落跑。
   每级碰壁 → 一次 Owen 午饭。Jacobo 全程旁观（监视戒不掉），嫉妒走基础设施通道：Jack 的门锁换更好、楼层 gym 升级、大堂灯全修——**他的真心做基础设施，嫉妒也做基础设施**。Maggie 第一个起疑。
3. **Owen 追求期**：午饭链 → 风控报告 → 追求升级。Owen 此阶段只知 Jack 的失落有个形状，不知对手是谁、更不知对手是自己的被投创始人。
4. **offer 与拒绝**：形婚+代孕文件夹；"违约金太高了"；Jacobo "今天就让你怀孕" 冲场；Jack 屁颠跟人走，Owen 吃牛排。
5. **同归于尽**：Rachel 空降 CTO；董事会批准那场戏——Jacobo 看见简历血凉一半，全程扑克脸批准（否决=在投资人面前露私情），散会对 Jack 憋出："……你们那个 Owen 校友，给我招了个 CTO。"Jack："……Rachel?"——知识级联开闸。
6. **爆发单元**：Rachel 已在楼里（总账房在场），她的"置身事外"被冲击波测试，冷漠从选择升级成判词。
7. **婚礼单元**：Rachel 已是四人组成员；未婚夫出处见第二节 5（可选）。

## 六、四人工作组（工作 A 线）

- **能力咬合**：Jacobo 对客户端和家族 / Owen 对资本和董事会 / Rachel 对技术组织和工程纪律 / Jack 对系统和救火。前两个人定价，后两个人干活。
- Rachel 招募 Jack 的 pitch 语系（零煽情，她的爱语=把 Jack 当市场参与者）："我缺一个能打的。你现在被履历低估了，这是套利机会。来不来？"
- **报价单升维**：真相爆炸的当量 = 四人饭碗 + 投资人脸面 + 一栋楼产权。工作越顺，爆炸越贵——丧的浓度改从资产负债表渗出。
- **昼场 quota 危机**：Jack 成了 CEO 直属公司员工，与 Jacobo 白天见面有了无数正当理由——双地址配额制被日常性冲垮，险情燃料翻倍。
- 第一场技术危机候选：上线前模型在金融 corner case 上集体幻觉（一个 bug 就是一场爆仓——Jack 修的不是代码，是当年没人替他修的那个东西）。
