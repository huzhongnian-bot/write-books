# 《水属性的魔法师》角色卡

---

## 凉

### 描述

性格：乐观务实、努力而不硬撑，粗神经乐天，面对巨龙也能迅速镇定；脱线中二、爱吐槽爱抬杠，满嘴轻小说与RPG梗，重视吃饭胜过一切（最爱日式咖喱与海鲜），滥好人，执着于给招式起帅气的名字。战斗时却极度冷静谨慎、擅长动脑，审讯时会露出笑咪咪却恐怖的表情。信奉亡父「别太辛苦工作」的理念，追求慢生活。称呼阿贝尔「守财奴剑士」。
能力：水属性魔法师，无需魔杖、无咏唱即可全力发动，生成速度破格，还能在远离自身约四十公尺高空生成魔法（被疑为「原创魔法」）。代表招式：〈喷射水柱〉（最多256道齐射、可作推进器音速机动）、〈冰枪术〉（可256连发）、〈冰墙〉系（透明、可叠至10层、包装、悬空砸落）、〈冰棺〉〈冰锁〉〈结冻路面〉〈骤雨〉〈热水沸腾〉〈磨料水刀256〉（王牌，曾瞬杀魔王子）〈永久冻土〉（一招冻结全村）、探查技〈被动声纳〉（五百公尺外探敌不被察觉）、〈干扰〉（封印敌方魔法）。以地球理化知识（氢键、分子振动、水刀）开发魔法。剑术师承水之妖精王杜拉汉，佩水属性专用剑「村雨」，悟出以水魔法反作用力加速的「水装」；兼修炼金术，继承暗杀教团首领哈桑·沙巴的三册笔记。隐藏特性「不老」，体内涌出浓度超过地脉的妖精因子。
成长线：地球人三原凉，十九岁父母双亡继承公司，二十岁生日前夜被卡车撞死，经管理者米迦勒（暂名）保有记忆转生到异世界「法伊」，许愿「在不会有人来的地方享受慢生活」→ 在隆德森林独自修行二十年：钻研水魔法、与独眼刺客鹰两度死斗、拜无头骑士杜拉汉为师获赠村雨、败给海怪库拉肯立志复仇、邂逅龙王卢温 → 救起漂流剑士阿贝尔并受托出山，注册卢恩冒险者公会D级 → 日蚀封廊初战恶魔蕾欧诺儿 → 独闯地下城四十层瞬杀魔王子救出阿贝尔 → 与精灵瑟拉结为师生每日模拟战 → 惠特纳什为护室友与「爆炎魔法师」奥斯卡死斗后和解 → 粉碎暗杀教团、齐马利诺被传为「红色魔王」 → 任威利王子魔法老师、单灭教团总部悟出「水装」 → 王都动乱奋战，再战蕾欧诺儿以村雨斩其首获胜，断臂自行接回。黑发黑眼、日晒浅黑皮肤、看起来不到二十岁，自称「永远的十九岁」，常穿妖精王所赠的白底长袍与淡水蓝披风。

### 性格

乐观务实、努力而不硬撑，粗神经乐天；脱线中二、爱吐槽爱抬杠，满嘴轻小说梗，重视吃饭胜过一切（最爱咖喱与海鲜），滥好人，执着于给招式起帅气的名字。信奉「别太辛苦工作」，追求慢生活；战斗时却极度冷静谨慎、擅长动脑，审讯时会露出笑咪咪却恐怖的表情。

## 奥斯卡·鲁斯卡

### 描述

性格：勤劳懂事、重情，沉默寡言但有礼貌地拜托便会帮忙；凡事认真、适应力强，学习上是全方面天才，像干沙碰到水一样吸收知识。对盗贼怀有深仇大恨、杀人毫不留情；对金钱没有执着；练兵铁腕，教学上以夸奖激励成长；私下却常粗心（忘带公会卡）。内心曾因养父遇害而「结冻」，在库科瓦侯爵夫人玛丽亚身边逐渐融化，「喜怒哀乐，他的表情回来了」。
能力：「爆炎魔法师」，无咏唱火属性魔法——能生成心中描绘的魔法，看过一次他人魔法在心中想像即可学会。火魔法抵达操控电浆的境界（温度约摄氏一亿度）：〈穿刺火焰〉（白热极细点状贯穿，可一百八十度转弯，另有扩散连射）、〈炎枪连弹〉（十连发高贯穿炎枪，一发可打穿帝都城墙）、〈天崩地裂〉（大范围炎弹可烧毁整座城市）、〈炎狱〉（白色炎壁火牢）、〈炎块〉；能精准点燃人的声带、操控火焰扬起的烟。无属性〈障壁〉（物理叠加魔法）硬度能硬接圣剑全力突刺且瞬间修复。剑术足以跻身骑士团顶尖；另有弓箭、磨刀与打铁基础。传闻「一击烧死一千名王国军」「一击让飞龙灰飞湮灭」。
成长线：生于边境佛斯特村，铁匠拉桑的唯一徒弟，天生烈焰般的红发是「受火神眷顾的证明」→ 六岁村庄夜袭双亲被波斯寇那杀害，漂流获救 → 受隐士大人（路克·罗希可男爵）收留教养四年 → 十岁亲眼见隐士大人被杀，红发尽白、不再笑，一个月后消失 → 化身「盗贼猎人」半年灭两个盗贼团、手刃波许，得知波斯寇那逃往帝国 → 赴帝国途中练成〈穿刺火焰〉，与C级队伍「乱射乱击」协力讨伐帝虎 → 帝都任库科瓦侯爵夫人护卫并融入侯爵家 → 成为第十一皇女菲欧娜坚称的「师父」，助她驯服魔剑渡鸦 → 惠特纳什误袭与凉死斗、全数攻击被挡，战后亲自道歉和解，归国闭关逾月 → 任皇帝魔法师团副师团长、以功绩晋升男爵，一对七完胜勇者队伍 → 武斗大赛预赛一人砍断八名围攻者的双手晋级；杀亲仇人波斯寇那仍在追杀中。白发褐肤，十八岁一百八十五公分的美男子，略带阴郁的气质。

### 性格

沉默寡言、不苟言笑，凡事认真、勤劳重情；对盗贼杀人毫不留情，对金钱无执着；练兵铁腕、教学以夸奖激励；私下常粗心。内心曾因养父遇害而结冻，正逐渐融化。

## 瑟拉

### 描述

性格：寡言认真、好战重约定，对模拟战十分期待；热心敏锐，一眼就能看穿对方的隐瞒。在凉面前有俏皮一面；大书虫，常驻北图书馆被暗称「北图书馆馆主」；爱吃咖喱、食量不小，被调侃会结巴否认。对凉温柔纵容，对威胁凉的人冷酷无情，训练严格到受训精灵充满恐怖与畏惧。
能力：精灵（半妖精）风属性魔法师兼剑士，称号「风之瑟拉」，约两百岁，卢恩边境伯爵领地骑士团剑术教官。绝技「风装」：以风魔法无意识地提升一切身体动作的速度与力量，身缠风可以音速行动，魔法控制跟呼吸一样自然、魔力量深不见底，速度可能超越妖精王杜拉汉，连全盛期的英雄麦格拉斯都自认赢不了发动风装的她。剑术超凡入圣（曾独自撂倒演习场几乎所有骑士；魔力耗尽状态下纯以剑术决斗大魔鬼逾一小时后斩首获胜），射箭技巧超一流，能与自然精灵对话，能凭种族特性辨识妖精王之物。
成长线：卢恩唯一的精灵冒险者，B级队伍「风」唯一成员，在卢恩城是超越阿贝尔与菲尔普斯的传说 → 北图书馆与凉邂逅，共同调查大海啸与日蚀的关联 → 演习场模拟战折服凉，认出他的妖精王长袍，结为师生、每日对练（凉尚未赢过），要求他直呼其名 → 收到凉的信后失态，强行加入骑士团队伍飞奔王都 → 王都动乱中任精灵自治厅防卫指挥官，谎称「支撑到日落支援就会来」鼓舞众人，魔力耗尽后鏖战大魔鬼，最后一瞬发动风装绕背斩首获胜 → 帝国武斗大赛预赛碾压围攻者。白金色长发、碧绿色大眼、尖耳、晶莹剔透的白皙肌肤，约一百七十公分的绝世美女，美到宛如一幅绘画。

### 性格

寡言认真、好战重约定；热心敏锐的大书虫，爱吃咖喱食量大；在凉面前有俏皮一面，对凉温柔纵容，对威胁凉的人冷酷无情，训练严格。

## 蕾欧诺儿

### 描述

性格：戏谑傲慢，痴迷与强者战斗（「这可是让人庆幸自己活着，开心无比的事件啊？」）；重诺守信，发誓不对阿贝尔出手便遵守；战败坦然认负，放话再战。
能力：恶魔，《魔物大全》特级篇记载「来源不明」「祈祷不要遇到」，强弱不定但最弱也能单体消灭一座城市。多属性魔法：火属性业火（命中前分裂如真空斩）、风枪、土墙防御、〈焰枪〉〈焰枪五连〉〈石笋〉〈连弹〉、〈风爪乱舞〉（破解磨料水刀的风属性版数量战术）；借风魔法近乎瞬移的音速冲刺、制造残影分身；从亚空间取剑；高速再生，被斩首也能接回——但被妖精王的剑「村雨」所伤则无法用普通再生手段接合。剑术精湛，能一挥手消灭整批冰枪。能在日蚀时展开特殊空间「封廊」把目标单独拉入（有时间制约）。
成长线：全名蕾欧诺儿·乌菈卡·阿尔武尔克尔克 → 日蚀封廊中与凉激战未分胜负，自报名号留下「凉要死在我的手下」的宣言离去 → 在西方人工祭坛现身，一剑刺穿勇者罗曼腹部、否认自己是魔王，取走连接两地「调整数量」的宝珠，并告诉罗曼人类中有比他强一万倍的存在（指凉）→ 王都动乱后再现身，夺伪装村庄神殿的宝玉、以〈石笋〉屠尽三十余名盗贼，掳走暗之神神官当「样本」→ 依约与凉单挑，被村雨斩首无法当场接回头颅，认负后抱头携老人退入「门」，宣言「下次我一定会赢」。身高约一百七十五公分的美女，有头角与黑色细长尾巴，口头禅式的凄惨笑容，存在感堪比贝西摩斯与格里芬。

## 阿贝尔

### 描述

性格：直率、重义理、脸皮薄，不擅长兜圈子，常因失言暗自后悔，坚持要报答恩人；认真善良有常识，厚道爱请客（被凉反复认证为「大好人」），总被凉耍得团团转也只能苦笑。务实冷静，审讯时扮演「惨无人道的剑士」实则心软；对敌人有骑士风度，击败炎帝后拒绝补刀「我随时候教」。
能力：不会魔法的纯剑士，B级冒险者、B级队伍「赤红剑」队长，实力据说已达A级的天才剑士，修行「修姆流」剑术。斗技：侧步、完全贯穿；剑技：绝影（以最小动作闪避含魔法在内的一切远距离攻击）、零旋（右脚为轴旋转四十五度，零距离闪避冲锋并顺势刺击）。持不会折断的赤红魔剑，直觉极准能看穿认知妨碍长袍，后练成一流箭术。
成长线：奈特莉王国国王施塔福四世的第二王子阿尔伯特·贝斯佛德·奈特莉，八年前十八岁成年即离开王宫成为冒险者 → 乘船被库拉肯击毁漂流至隆德次大陆，被水属性魔法师凉所救，委托他护送回卢恩，途中翻越魔山猎飞龙 → 大海啸中以「绝影」近身哥布林王、喝令琳「连我一起打穿」完成击杀 → 地下城四十层遭魔王子碾压被凉救下 → 惠特纳什调停凉与奥斯卡的死斗促成和解 → 两度对决「炎帝」弗朗姆，二战看穿魔剑「巨怒」的特性反杀获胜 → 被王太子登录为英雄宝库钥匙第二持有人，潜入王都调查国王异状，王子身份渐露 → 王都动乱中奋战，斩下紫发人尤里乌斯头颅。黯淡红发，身高约一百九十公分，体格健壮不胖，手上有拿剑的厚茧。

直率重义理、脸皮薄，坚持报恩；认真善良有常识，厚道爱请客，总被凉耍得团团转；务实冷静，审讯时扮演恶人实则心软；对敌人有骑士风度，拒绝对败者补刀。
