# 批次19 角色与设定笔记

# 角色

- **莉薇雅**：浮游岛型运输艇的女性操纵者，紫发蓝眼（战斗时双眼发蓝光、紫发熠熠生辉），隶属与浮游大陆相关的组织。性格暴躁冲动，坠落时痛殴控制台大喊「因为检测出异常值，浮游机关失去了动力……现实就是出现了异常值」场景中对尤里乌斯吼「不用你说我也知道是异常值！」（56章）；但对下属下令时声音转为长官式冷峻，准许解除「一阶段」限制并命其「排除所有接近的事物。不管是食人魔，还是人类」（56章）。实力深不可测，一杆长枪令凉与阿贝尔感到「快被压扁」的压力；一眼识破凉持妖精王的剑与长袍、浑身涌出妖精因子，并断定异常值肇因是凉「一个人类居然喷出比地脉还强的数值」（56章）。回收尤里乌斯与德鲁苏斯后带岛凭空消失。

- **尤里乌斯**：莉薇雅的男性同僚，紫发蓝眼，即凉口中的「紫发一号」。曾在卢恩城与凉、阿贝尔交战，在温格史东被琳的〈枪林弹雨〉打成蜂窝（56章回忆）。冷静无抑扬，坠落时「平淡地说出事实」。解除「一阶段」限制后战力惊人：单手施放火焰瀑布〈法伊尔佛尔〉压制凉的〈积层冰墙〉，另一手挥剑与阿贝尔交锋，还能瞬间构筑弹开冰枪的石墙〈穆尔斯拉碧斯〉，并施放爆炸性小型陨石〈米提尔因培尔〉与火球〈柯尔斯加雷〉。胸口被刺穿也不死（「心脏不一定只有一个」），最终被阿贝尔斩首，身体被莉薇雅回收。

- **德鲁苏斯**：紫发第三人，被莉薇雅从冷冻睡眠唤醒辅佐尤里乌斯护船（56章），即凉口中的「紫发二号」。与阿贝尔交战时中凉的〈结冻路面〉滑倒，被阿贝尔踢中头部昏迷，后被莉薇雅一并带走。

- **凉**：水属性魔法师主角。本章展现的强大：〈冰枪术5〉〈永久冻土〉瞬杀五只食人魔（56章）、以冰墙自空中坠落压扁魔物开路、〈喷射水柱256〉瞬间斩首视野内上千魔物（57章）。体内涌出妖精因子，浓度超过地脉，是浮游岛坠落的肇因；该因子有驱邪效果，使暗属性〈奴役〉对他无效（「对阿贝尔没效的招数，对我怎么可能有用！」58章）。新招：〈干扰〉——混入对方生成途中的魔法使其溃散（向哈桑学来，闭眼配合〈被动声纳〉才成功）；〈喷射水柱推进器〉——喷水机动的音速移动。被蕾欧诺儿砍断左前臂，靠水属性魔法以微米级精度用冰膜接合骨骼、神经、血管，配合肯尼斯药水自行接回（58章）。有六名魔法徒弟（因培里公国五名商人见习生与威利王子）。爱吐槽轻小说王道桥段，性格脱线却战斗时极度谨慎（「凉在这种时候真谨慎啊」——阿贝尔，58章）。

- **阿贝尔**：B级冒险者剑士，凉的最佳搭档，实为奈特莉王国国王施塔福四世次子（雷克斯差点叫破「陛……父亲」，56章）。剑术超绝，斩下尤里乌斯头颅；佩戴国宝级「平静的项炼」，数秒内可解精神干涉系魔法，并识破白发老人是「七神中暗之神的神官」（58章）。具有王族知识（如「自然精灵的守护」）。察觉有人跟踪后冷静应对，谈判时「陈述事实的时候，人的说服力会加倍」。对丽希娅有好感（被拥抱时脸红，57章）；答应丽希娅「一定会跟凉一起回来」（58章）。

- **雷克斯**：王都卫兵队副队长，阿贝尔的老友（知道其本名阿尔伯特与王室身分）。剑术「宛如会弯曲的鞭子」，是战场上的剑，出身成谜（56章）。指挥王城防卫，死守北小阶梯；面对食人魔时想起阿贝尔「把剑插进眼睛或耳朵」的战法，从阶梯跃下刺穿食人魔眼睛。沉稳尽责：「既然出现了，就只能处理」（56章）。

- **瑟拉**：精灵剑士，两百岁以上，白金色长发，卢恩城有名B级冒险者、卢恩骑士团剑术教官。自治厅防卫战中任指挥官，深知「指挥官说『输了』就一定会输」，故谎称「再撑一下！支撑到日落，支援就会来！」鼓舞众人（57章）。魔力耗尽、不用风装与大魔鬼（剑士型）纯以剑术决斗逾一小时，最后一瞬发动风装绕背斩首获胜。性格好战（「那我就只能成为第一个打倒『剑士』的精灵了」），对凉怀有特殊感情（被公主抱时害羞又高兴）。

- **长老婆婆（琉恩）**：精灵自治厅实际领导者，王国西方森林大长老之一，本名琉恩（57章首次自报）。见识广博，一眼认出罗曼是勇者（「周围飞舞的自然精灵数量非比寻常」），知晓大魔鬼、妖精因子等秘闻。幽默而严格（箭尽后命自治厅长官卡森今后「保管一百倍的箭矢」）。看好瑟拉与凉的关系。

- **札克·库拉**：奈特莉王国骑士团骑士，与史考蒂在威斯特伍德子爵宅邸避难后被救入自治厅。剑术比一般精灵熟练。防卫战后对瑟拉一见倾心，被阿贝尔劝「她只对强大的男人有兴趣」反而立志「从今天开始，我也为剑而生！」（57章）。

- **史考蒂·柯布克**：王国骑士团骑士，与札克一同避难、并肩作战（57章）。

- **卡森**：精灵自治厅长官，被长老婆婆严格命令战后储备百倍箭矢（57章）。

- **罗斯利**：自治厅内精灵（或与瑟拉熟识者），听到「大魔鬼」一词时侧头不解（57章）。

- **丽希娅**：「赤红剑」神官。知道大魔鬼在魔王军中「地位相当于将军」（57章）。接到卢恩神殿紧急委托随运送队先回卢恩，要求阿贝尔约好「一定会跟凉一起回来」（58章）。对阿贝尔有好感。

- **琳**：「赤红剑」风属性魔法师，希莱里昂的徒弟。察觉札克爱上瑟拉（「我猜他爱上瑟拉小姐了」，57章）。曾以〈枪林弹雨〉把尤里乌斯打成蜂窝（56章提及）。与沃伦担任丽希娅的保镳先回卢恩（58章）。

- **沃伦**：「赤红剑」成员，与琳一起护送丽希娅回卢恩（57、58章）。

- **罗曼**：西方诸国的勇者，诚实有礼的青年（「能借住在代表王国的魔法师希莱里昂大人的研究所，我们光荣之至」，57章）。剑术在阿贝尔之上（58章阿贝尔内心笃定），却曾被蕾欧诺儿「当成小孩子玩弄」。视力优异，最早看见冰墙自天而降。队伍借住希莱里昂的王国魔法研究所。

- **格拉汉姆**：罗曼队伍中的西方诸国神职人员，知道大魔鬼「比魔王子还强」（57章）。

- **高登**：罗曼队伍的火属性魔法师，对自治厅被贯穿的大门兴味盎然地观察（57章）。

- **伊登**：卢恩骑士团运送部队队长，驾卢恩边境伯爵纹章马车送肯尼斯到自治厅，称凉「凉阁下」（57章）。

- **肯尼斯·海伍德**：天才炼金术师、男爵。王都动乱时带炼金道具（王都防卫用兵器雏型）躲入卢恩边境伯爵宅邸。动乱后一周内把炼金术「从基础到奥义」传授给凉（凉自称升上高级），并与凉共同调制出顶级药水——修复力强大，成为凉接回断臂的关键（58章）。

- **奥伯利卿**：韩德尔诸国联盟执政官，王都动乱的幕后黑手之一（取得可疑「宝珠」引发魔物暴动），目标是瘫痪王国中枢、四个月后出兵逼因培里公国重新屈服（「因培里公，我一定要让你再次对联盟屈膝。」57章）。明知密探南西可能与帝国串通仍继续用她。阴险而张狂（「啊哈哈哈哈！」）。

- **兰伯**：奥伯利卿的辅佐官，谨慎忠诚，担忧南西与帝国串通（57章）。

- **威利**：德优王国第八王子，水属性魔法使用者，称凉为「老师」。动乱当天因接待奈特莉王国王太子而留在大使馆躲过一劫，钦佩王太子「指示好精准」（57章）。

- **科恩**：因培里公国C级冒险者，实为公国政府指名的间谍，「大战」时曾为公国从事幕后工作。动乱前接「立刻前往大使馆」的密信离开王都，新任务是潜入联盟首都杰克雷亚（57章）。

- **希莱里昂·巴拉哈**：奈特莉王国首席宫廷魔法师，三十年来地位不容动摇，琳的师父。动乱时追着某个人物去了东方而缺席，回来后见到勇者队伍借住自己的魔法研究所而错愕（57章）。

- **蕾欧诺儿**：有犄角与黑色细长尾巴的恶魔，痴迷与凉战斗（「这可是让人庆幸自己活着，开心无比的事件啊？」58章）。魔法威力在凉之上：〈业火〉〈焰枪〉〈焰枪五连〉〈石笋〉〈连弹〉〈风爪乱舞〉（破解〈磨料水刀〉的风属性版数量战术），能从亚空间取剑、以音速冲刺、制造残影分身。口头禅式凄惨笑容。重诺（发誓不对阿贝尔出手便遵守），透露宝珠用于「调整数量」、王都动乱「详情我不能说」。被凉斩首却因妖精王的剑无法当场接回头，认负后抱头掳走暗属性老人离去（「下次我一定会赢！我打得很尽兴。」）。

- **白发老人（暗之神神官）**：伪装村庄的领袖，白发及腰，持七色吊绳与石雕长杖。想将阿贝尔的魔剑「奉献给神」，称光之女神为「伪神」。在隐藏神殿施展强化版〈奴役〉（「据说就连魔王都能控制」），对凉、阿贝尔均无效后打算强抢，最终被蕾欧诺儿〈石笋〉击昏掳走当暗属性魔法「样本」（58章）。

- **光头男子／寸头男子**：盗贼团头目与手下。光头「额头散发出知性印象」，提出用「非卖品」交换魔剑的谈判（58章）；寸头「额头感觉不到知性」，嘲讽凉没锻炼身体。二人均被蕾欧诺儿的〈石笋〉贯穿喉咙而死。

- **（提及未出场）**：哈桑·沙巴（暗杀教团首领，〈干扰〉与〈陨石〉的原创者）、亚瑟·贝拉席斯（宫廷魔法团顾问，曾协助凉测试冰冻魔法）、艾特（神官）、尼尔斯（其村有隐藏神殿）、施塔福四世（奈特莉国王，阿贝尔之父，被奥伯利卿察觉「不太对劲」）、王太子（阿贝尔之兄，体弱，动乱时访问德优大使馆）、弗立维公爵雷蒙（王弟，与联盟密约又勾结帝国）、南西（联盟密探，被派往王国西部）、兰夏斯（帝国第二十军「影军」将军，已进入王国西部）、弗莱彻子爵（死于动乱）、克莱夫·史坦波（中央大学校长，命名「门」）。

# 设定

- **浮游岛型运输艇**：外表是小岛、内部装载浮游机关在天空飞行的船，本艘全长两百公尺仍算「小规模」。因凉的妖精因子超出检测阈值（异常值）导致浮游机关失效坠落；改用「帮浦航行法」可起飞但会损坏浮游机关。乘员受「一阶段」限制，解除后紫发发光、战力大增（56章）。

- **浮游大陆**：紫发人所属组织的背景存在，凉与阿贝尔自精灵长老故事起便怀疑其与紫发人有关，本章获证实（56章）。

- **奈特莉王国**：中央诸国南方大国，王都即首都「水晶宫」（艾许顿选为首都之地）。十年前对韩德尔诸国联盟的「大战」中大获全胜（57章）。

- **王城／北小阶梯**：王城地下有重保管室，藏有「烟雾蠢动的黑色球体」（委托亚瑟鉴定的物件），被坠落的岛刺穿后魔物涌出。北小阶梯是官员进出国王办公室的隐蔽楼梯，宽五公尺（56章）。

- **王都卫兵队／第一、第二近卫连队**：卫兵队守护王都治安，多为认真之人；第一近卫连队是国王贴身侍卫，全是贵族、特权意识强、瞧不起他队；第二近卫连队是王太子专属战力，唯才是举且须王太子面试（56章）。

- **大魔鬼（Archdevil）**：魔鬼的另一进化途径（非魔王→魔王子路线），比「魔王幼体」魔王子更强，魔王军中地位相当于将军。分「剑士」「魔法师」等类型；历史上精灵曾击败「魔法师」型但牺牲上百人（57章）。

- **风装**：瑟拉的魔法，身缠风以音速行动。可在战斗中刻意不用、积蓄魔力后瞬间发动（57章）。

- **村雨**：凉的佩剑，「妖精王的剑」，传说为「拔刀散玉之冰刃」，刀刃由冰生成、细而弯曲（武士刀型）。师父所赠。被其斩伤者无法用普通再生手段接合（蕾欧诺儿的头接不回去）（58章）。

- **妖精王的长袍**：凉穿的长袍，具防御力（挡下〈焰枪五连〉中瞄准右肩的一发）（58章）。

- **妖精因子**：凉体内涌出的神秘因子，浓度超过地脉，对持有妖精因子者是「贵重的营养补给来源」，并有驱邪效果（使〈奴役〉无效）；也是浮游岛坠落的肇因（56、58章）。

- **平静的项炼**：阿贝尔随身携带的国宝级道具，可在数秒内解除异常状态与精神干涉系魔法（58章）。

- **〈奴役（Slave）〉**：暗属性精神干涉魔法，在暗之神神殿强化下「据说连魔王都能控制」，但被项炼与凉的驱邪体质破解（58章）。

- **七神／暗之神／光之女神**：光之女神以外的神明已从中央诸国表面历史消失；白发老人是暗之神神官，称光之女神为「伪神」；暗属性魔法现今极为罕见、暗属性魔法师「很贵重」（58章）。

- **宝珠／宝玉**：恶魔阵营称为「宝珠」的球体，功能是连接两地「调整数量」——把魔物过多的「某个地方」的魔物移送至他处（卢恩「大海啸」即因此发生）。卢恩地下城四十层与中央神殿地下五层回收的为黑色变体；伪装村庄神殿中的为完好透明水晶球。王都动乱「似乎用了宝珠」但性质不同，详情被蕾欧诺儿保密（58章）。

- **「门」**：中央大学校长克莱夫·史坦波命名的黑色四角形空间通道，高五公尺宽四公尺，蕾欧诺儿借此出现与撤退（58章）。

- **〈干扰（Jamming）〉**：哈桑开发的魔法，在对方魔法生成途中混入自己的魔法使其溃散，可封印敌方魔法；需要超乎想像的精密控制与生成速度，凉靠闭眼+〈被动声纳〉才成功（58章）。

- **〈冰盾改二〉**：凉对哈桑战时开发，空气中的水蒸气接触异物自动凝结成数以万计的小型冰盾并连锁反应（56章）。

- **〈磨料水刀256〉**：凉的王牌，两百五十六根水线切割敌人，本章被蕾欧诺儿的〈风爪乱舞〉以数量完全破解（58章）。

- **〈喷射水柱推进器（Water Jet Thruster）〉**：凉的新招，以喷水反作用力做音速机动，可单脚腾跃并如太极拳般自转卸力（58章）。

- **〈特级治愈〉**：高等神官奥义，连缺损部位也能再生；缺损修复须在二十四小时内（58章）。

- **斗技**：剑士、长枪手等物理职业的特殊技能，约一百年前在中央诸国出现并传开，首个使用者不详；是否类似魔法学界尚无定论（58章）。

- **咏唱／触发语（Trigger Word）**：大地母神的婆婆称「咏唱本来就不存在」；罗曼队伍只说触发语。凉质疑「Trigger」（扳机）与〈枪林弹雨（Bullet Rain）〉等词源于枪枝概念，而中央诸国尚无枪枝（仅有国家机密级的「黑粉」），构成世界之谜（58章）。

- **韩德尔诸国联盟**：中央诸国东方大国，首都杰克雷亚，十年前「大战」败给王国、割地并使属下小国独立（57章）。

- **德布希帝国**：中央诸国北方大国，全面压制他国；帝都每四五年举办知名武斗大赛；第二十军「影军」由兰夏斯将军率领，已潜入王国西部（57、58章）。

- **因培里公国**：十年前「大战」后脱离联盟完全独立的小国，资源丰富，以冒险者从事情报活动；奥伯利卿计划四个月后出兵逼其重新屈服（57章）。

- **德优王国**：威利王子的国家，其大使馆位于王都东区北边而在动乱中幸免（57章）。

- **德欧法姆／阿伯戴尔**：王都南方的卫星大城与归途驿站，南街道经此通往卢恩城（58章）。

- **大海啸**：卢恩城周期性魔物涌出事件，本章证实是恶魔阵营用宝珠「调整数量」所致，且今年数量偏多（58章）。

- **魔法无效化**：贝西摩斯的魔法无效空间、独眼刺客鹰进化后获得的魔法无效能力（凉在最后一战体验过）（58章回顾）。

- **「法伊」**：这个世界（星球/大陆）的名称，凉内心将地球与之对照（58章）。
