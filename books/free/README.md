## 大时间轴速览（以遥的学年为准，日本学制4月始业）

1. **小学**：遥·真琴·渚在岩鸢SC（教练笹部吾朗）；凛小6从佐野小学转入，四人混合接力夺冠，埋时光胶囊「For the Team」；凛毕业后赴澳大利亚。同期宗介与凛是佐野小学挚友（因游泳理念不合散过接力队）。
2. **初中1年**（High☆Speed!）：遥·真琴·旭·郁弥入岩鸢中学游泳部（部长桐岛夏也、经理芹泽尚），县大赛混合接力夺冠；宗介代凛向遥挑战并转交凛的信。其后凛回国私赛负于遥→宣言弃泳→遥退部→队伍解体（旭转学、郁弥赴美）。宗介赴东京强校鲸津高中。
3. **高中2年夏**（S1）：凛归国入鲛柄学园，与遥重逢对立→岩鸢游泳部复兴（真琴部长、怜入部、江经理）→离岛合宿（真琴恐海症坦白）→县大赛凛胜遥→地区大赛怜让位、五人接力圆梦（犯规失格，羁绊修复）。
4. **高中3年夏**（S2 Eternal Summer）：**宗介带肩伤转入鲛柄**（全季暗线）；真琴打工教恐水少年确立教练志向；遥对未来迷茫、地区大赛弃赛；真琴摊牌东京升学与遥爆吵；凛带遥去悉尼找回梦想；全国大会岩鸢总第六；宗介地区大赛接力带伤拼完「最后一游」。
5. **毕业后春**（Take Your Marks）：遥真琴上京找房；凛赴澳；四段短篇过渡。
6. **大学1年**（S3 Dive to the Future）：遥入灯鹰大学（教练东龙司）与旭重逢；郁弥线（霜狼学院大学·日和）；真琴走训练师之路；宗介在东京接受右肩手术；全日本邀请赛遥拿到世界大赛门票。
7. **世界大赛**（the Final Stroke 前篇）：悉尼，遥被绝对王者阿尔贝托碾压、与凛史上最大决裂。
8. **大结局**（the Final Stroke 后篇）：和解→全明星合同集训→全日本选拔（宗介复出、改游仰泳）→福冈大会混合接力（宗介-郁弥-凛-遥）夺金→尾声遥剑指雅典。

## 宗介 × 真琴 二创向速查

- **原作交集**（两人直接同框较少，留白大=二创空间大）：
  - S1/S2 两人分属岩鸢/鲛柄两校，对手阵营；S2 县大赛·地区大赛接力同场（百太郎仰泳对真琴棒次几乎同时触壁是 ES 地区赛名场面）。
  - S2 ep8：真琴与遥从贵澄处最早得知宗介肩伤——真琴是「知情者」。
  - 《Road to the World 梦》新规：**真琴在东京书店偶遇宗介，新宿天台花园谈心**（宗介由此决意手术）——两人唯一一段正式的独处对手戏。
  - S3 东京时期：真琴在东京读大学+泳池打工，宗介在东京手术康复，地理上同城。
- **宗介关键节点**：佐野小学与凛的竹马线 → 东京鲸津高中过度训练致右肩伤 → 高三春转鲛柄隐瞒伤情 → 可乐罐试探暴露 → 地区大赛「最后一游」 → 凛「等你回来」 → 三校合宿被夏也点醒 → 东京手术 → FS 复出改仰泳 → 福冈接力夺金。
- **真琴关键节点**：童年渔夫海难（即凛之父）留下恐海症 → 岩鸢SC→岩鸢中学 → 高中任游泳部部长 → S1 合宿恐海坦白 → S2 ep6 与遥的200自对决 → ep8 教练志向萌芽 → ep11 与遥唯一一次爆吵 → 东京读大学走训练师路线。
- **数据存疑点**（写作前建议复核正片）：真琴身高 183/184/187 各源不一；宗介身高 185/186；宗介大学归属（pixiv记瀬鹿共立大学，日维基记「未上大学、回家业帮忙」，两说并存）；宗介复出项目为仰泳的说法源自百度百科。
