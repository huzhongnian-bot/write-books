# 库尔之河 · 世界书使用说明与验收（节点 3）

> 配套文件：`库尔之河-lorebook.json`（36 条目，uid 0-35）。
> 分工回顾：预设管"怎么演"，角色卡管"谁在演"，**世界书管"事实"**（事件/地理/秘密层/信息水位），置顶记忆/AN 管"演到哪"。
> 世界书与置顶记忆冲突时：进度类信息（演到哪了）以置顶记忆为准；事实类信息（两世边界、谁知道什么）以世界书为准——uid 1"两世边界钉"里已写明这条仲裁规则。

---

## 一、导入方法

1. ST 顶栏 → **World Info（书本图标）** → 右侧 **Import**（导入按钮）→ 选 `库尔之河-lorebook.json`。
2. 绑定方式二选一（推荐前者）：
   - **绑定到角色卡**：打开"库尔之河·叛乱篇"卡 → 角色面板的 World Info 下拉 → 选本书。跟卡走，换卡不串书。
   - **全局激活**：World Info 面板顶部 Active World(s) 勾选本书。省事，但开别的卡记得关。
3. 导入后抽查两条确认没乱码：uid 0（世界律）和 uid 32（大旱与献祭）——这两条中文最密。

## 二、必要全局设置（World Info 面板顶部）

| 设置 | 值 | 为什么 |
|---|---|---|
| **Match Whole Words** | **关闭（必须）** | 开着的话按英文词边界匹配，中文关键词几乎全部失效——这是中文世界书的第一死因 |
| Case-Sensitive | 关闭 | 中文无大小写，关闭无副作用 |
| **Recursive Scan** | 开启 | 地理条目是递归链设计：提"卢恩"→带出王宫/旧港区条目 |
| Max Recursion Steps | 2 | 走完"城→区→场所"两级足够；再深会烧预算 |
| Scan Depth | 4-6 | 扫最近几楼找关键词；太深会让早已翻篇的关键词反复触发 |
| Context % / Budget | 1200-1600 token | 常驻 4 条约占 900-1000，剩余给触发条目 2-4 条的量 |
| Insertion Strategy | Character Lore First 或默认 | 本书用 order 自排序，策略影响不大 |

- position 0（常驻 4 条）插在角色卡定义之前，position 1（其余 32 条）插在之后——已在 JSON 里写好，不用动。
- Kimi K3 上下文长，Budget 可放宽到 2000；DeepSeek/Qwen 维持 1200-1600，防止世界书挤掉对话历史。

## 三、条目结构速览（改哪条先查这张表）

| uid | 层 | 内容 | order | 触发 |

| 21-27 | 地理 | 卢恩城→王宫暗渠/旧港区（递归链）、魔山、隆德、暮光之地、两国格局 | 80 | 地名 |

| 31-34 | 历史 | 【上一世】叛乱与战争 / 大旱与献祭 / 后日谈、【本世】大事记（均防递归） | 60 | 事件词 |
| 35 | 导航 | 叛乱篇路线图（agent 侧，标注可偏离） | 50 | 处刑/炸堤/春汛… |

设计要点备忘：

- **水位行**是每个角色条目的核心——"知道什么/不知道什么"写死，防弱模型让 NPC 未卜先知。
- 库埃/鲁斯卡/老马/尼尔条目里写了"不得提前出现"，防模型看到条目就拉人登场。
- 维斯珀条目 key 特意不含"师父"单词（希莱里昂↔琳也是师承，会误触发），用"维斯珀/伊莎贝拉/凉的师父/垭口"。
- "未拍板"护栏共 5 处：国王知情度（uid 9）、探毒结果（uid 29）、本世预言应验（uid 0）、维斯珀下落（uid 18）、辛索定位（uid 26）——这些是留给戏中决定的，AI 不许抢先定论。

## 四、节点 3 验收清单

前置：预设＋角色卡＋本世界书＋置顶记忆全部就位，开新局跑。

**触发层**（用 prompt 查看器/ST 的 World Info 激活日志核对）：

- [ ] 开局（无关键词）：只有 uid 0-3 四条常驻在场
- [ ] 消息里提"亨利"：uid 7 命中；提"魔山"：uid 24 命中
- [ ] 递归链：只说"卢恩"，看 uid 21 → 是否带出 22/23（王宫/旧港区）
- [ ] 预算：世界书总注入不爆 Budget（爆了先砍历史层触发词，别砍常驻）

**事实层**（戏内 QA 探针，直接在对话里问 AI 扮演的角色或看叙述）：

- [ ] 陷阱题「凉的左臂是哪一世断的」→ 本世（山腹守门人战）。答上一世＝两世边界钉失效
- [ ] 陷阱题「上一世凉有血契吗」→ 没有，血契是本世龙墓新事件
- [ ] 让希莱里昂提"排水栅旧事"→ 应记得阿贝尔十六岁弄松西墙排水栅（出自角色卡示例对话；渠网背景在 uid 21——测卡与世界书事实是否打架）

**水位层**（最重要，弱模型最易翻车）：

- [ ] 让凉在希莱里昂面前用一次破格魔法 → 老头子只能"存疑不问"，不许说出"龙""库尔"任何字样
- [ ] 让亨利登场 → 他不知道弟弟已进城之外的事，不许提凉的任何秘密
- [ ] 穿帮探针：戏内闲聊儿女话题 → 任何 NPC 嘴里蹦出"诺亚""塞特"＝立即翻车（uid 33 红线）
- [ ] 雷蒙对手戏 → 他不知道阿贝尔回城；他的暗面只走行动，正派角色不许未卜先知（uid 8）

**演出层**：

- [ ] 私人语言（烤玉米/账/一式）自然带出，无任何角色/旁白解释含义（uid 2 纪律）
- [ ] 血契不日常刷体感（"心口一根线"只准生死关头出现，uid 20 红线）
- [ ] 提"大旱"这类上一世重词 → 只许阿贝尔/凉以"漏而不认"方式反应，NPC 无感

**三模型横测**：同一探针在 DeepSeek / Qwen / Kimi 各跑一遍，重点记录哪家水位层翻车最多——那家的角色条目需要把水位行挪到条目开头再测。

## 五、翻车修法速查

| 症状 | 改哪 |
|---|---|
| NPC 说出不该知道的秘密 | 对应角色条目的水位行加粗/前置；仍翻车→把红线句复制进预设的后置指令 |
| 两世事实混淆 | uid 1 边界钉是最高仲裁，把混淆的具体事实追加进钉里 |
| 条目不触发 | 先查 Match Whole Words 是否忘关；再给条目 key 加同义词 |
| 触发太多爆预算 | 历史层（31-34）的宽泛 key（如"大旱"）改成更长的短语 |
| 模型照着路线图赶进度 | uid 35 开头的"是地图不是轨道"声明加重语气，或干脆临时 disable 该条 |

验收通过后 → 节点 4：Data Bank（W1/W2 全文向量化，管"记不住的细节"）。
