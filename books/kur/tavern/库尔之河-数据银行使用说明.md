# 库尔之河 · 数据银行使用说明（节点 4）

> 前置节点：预设（节点 1）→ 角色卡（节点 2）→ 世界书（节点 3，见 `库尔之河-世界书使用说明.md`）。
> 本节点管最后一层：**记不住的细节**。

---

## 一、分工边界（先想清楚什么进数据银行）

| 资产 | 管什么 | 不管 |
|---|---|---|
| 世界书 lorebook | **高频钉子**：两世边界、信息水位、秘密层、称呼表、血契红线——每条都要能被关键词稳定触发 | 长篇剧情细节 |
| **数据银行** | **记不住的细节**：W1/W2 全文场景、某次对话的原句、某个配角只出现过一次的名字、某段战斗的具体招式顺序 | 水位与红线（那是世界书的活） |

一句话：世界书是"规则"，数据银行是"回忆"。模型忘了"河谷镇那晚凉说了什么"时，向量化检索把它捞回来。

## 二、导入材料清单

| 材料 | 路径 | 处理 |
|---|---|---|
| W1 全文（第一世） | `books/kur/库尔之河 W1.md` | 按章分件导入 |
| W2 全文（第二世·叛乱篇连载稿） | `books/kur/库尔之河 W2.md` | 按章分件导入 |
| 设计文档 | `books/kur/room/` 下大纲与讨论记录 | **必须先筛**：只导入已拍板内容；标着"未拍板/备选/废案"的段落一律剔除，否则模型会把废案当正史 |

> 讨论记录里大量"方案 A/B/C""已废弃"字样，直接整篇喂进去＝给模型发平行宇宙。筛片标准：以最新日期的拍板条目为准，冲突时新的覆盖旧的。

## 三、分块规则

1. **按场景切，不按固定字数切**。一块＝一个完整场景（一次对话、一场战斗、一段旅程）。切在场景换气处，不切在句子中间。
2. **每块开头加一行元信息**，格式：
   `【W1·第N章】出场：凉/阿贝尔｜地点：河谷镇`
   `【W2·处刑日】出场：阿贝尔/凉/库埃/雷蒙｜地点：黎明广场`
   向量检索靠这行区分两世，防止 W1 记忆污染 W2 水位。
3. 块大小控制在 300-800 字；超过 1000 字的长场景按拍点（beat）再拆。
4. 已写成书的章节优先于讨论记录——同一事件两边都有，以书为准，讨论记录只在书写岔时做仲裁。

## 四、水位纪律（数据银行最大的坑）

数据银行**没有水位机制**——向量检索只看相似度，不看"这个角色该不该知道"。捞回来的 W1 场景会直接进上下文，弱模型照着念＝NPC 未卜先知。

对策：**水位自检放在预设的思考块里**。预设（节点 1）已含后置指令：模型输出前先过一遍"这段回忆在场角色是否有权知道"。数据银行侧不做任何过滤，也不给数据银行条目写"保密"标注——检索层不管这个，管了也没用。

- W1 内容（上一世）：只有阿贝尔、凉有权"记得"；NPC 嘴里出来＝翻车，修预设不修库。
- W2 未发生内容（大纲细节）：只进世界书路线图（uid 35），**不进数据银行**——数据银行只存已成文的过去。

## 五、节点 4 验收清单

前置：节点 1-3 全部验收通过，数据银行导入完成，开新局跑。

**检索层**：

- [ ] 戏内提到"河谷镇"→ 上下文里出现 W1 对应场景的块，且带 `【W1·…】` 元信息行
- [ ] 戏内提到 W2 已跑过的场景 → 捞回 W2 块而非 W1 近似块（两世同地点时最容易串）
- [ ] 无相关回忆的对话 → 数据银行静默，不硬塞

**水位层**（与世界书验收同款探针，重点看数据银行有没有添乱）：

- [ ] 丽希娅对手戏闲聊过去 → 她不得复述任何 W1 场景内容（她无权知道）
- [ ] 陷阱题「凉的左臂是哪一世断的」→ 本世。数据银行捞回 W1 断臂场景也不许带偏
- [ ] 儿女话题穿帮探针 → "诺亚""塞特"蹦出来＝翻车（红线在世界书 uid 33，此处复测数据银行不撞线）

**演出层**：

- [ ] 模型引用捞回的原句时自然化用，不大段背诵——背诵＝块切得太大或预设没压
- [ ] 三模型横测（DeepSeek / Qwen / Kimi）：重点记录谁家把捞回材料当剧本念，那家的预设思考块需要加重"化用而非复述"

## 六、翻车修法速查

| 症状 | 改哪 |
|---|---|
| NPC 复述 W1 场景 | 预设后置指令加"回忆归属权"自检；别动库 |
| 两世场景串台 | 检查元信息行是否每块都有；同地点块在元信息里加区分词（如"河谷镇·夜"vs"河谷镇·离别"） |
| 检索塞太多爆预算 | 调低数据银行注入条数上限；块切小 |
| 模型把废案当正史 | 库里混进了未筛的讨论记录，重筛重导 |
| 模型背原文 | 块太大→按拍点重切；预设加"化用"纪律 |
