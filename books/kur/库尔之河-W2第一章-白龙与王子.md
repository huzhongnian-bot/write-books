# 库尔之河 · W2 第一章「白龙与王子」

> 2026-08-24 由《库尔之河-W2剧情脉络.md》差分立章。【亲妈拍板章节范围】：自海边捡到阿贝尔起，至两人出龙墓、阿贝尔告知凉自己的二王子身份、请求凉帮助自己回国解决叔父叛乱问题止。机制拆解与技法见《W2-走向讨论-2026-08-23.md》；本文件只收剧情事实，按章内时序排列。

## 本章前提（全书设定的章内用量）

- 双记忆互演：凉**海滩捡人时已恢复 W1 全部记忆**【拍板】；阿贝尔木屋醒来即恢复 W1 全部记忆（含后六十年全程）。两人互演"初见"：只漏，不证。
- 凉的档案断在雨里：他不知道 W1 终局细节（雨的验收、诺亚、自己的身后名、回归机制）。
- 章内贯穿暗线：阿贝尔带着 W1 总时刻表（父王被毒杀、王兄之死、叛乱、断桥、战争、旱灾）——木屋养伤的每一天都是那杯毒酒的进度条。

## 一、海滩捡人

- 凉在海滩捡到昏迷的阿贝尔，带回木屋。阿贝尔昏迷的五天里，凉是全场唯一清醒的知情人（倒置窗口）。
- 阿贝尔醒来，两人开始"初见"表演。着急联系同伴＝校准时钟：确认世界还在 W1 轨道上。

## 二、木屋与森林：不过山

- 凉的决定：**不过山**，把隆德森林和木屋当一辈子牢房——隔离工程（他是单点故障：过山即旱），不是自怜。
- 阿贝尔提出要一个人过山 → 凉的"怄"（怄自己，不是吃醋）对内加压 → 誓言破产，同行。"我恐怕只能把你送到山顶"本身就是漏。

## 三、狼崽钥匙

- 凉在陷阱里意外套到霜脊狼崽 → 治好 → 归还 → 狼王**芬里尔**＝卢温龙王的守墓人一系 → 山腹入场券（这一世门票是治好一只狼崽：道德锁取代战斗锁）。
- 凉的静默清偿：上一世冰匕刺瞎头狼的眼，这一世同一双手救狼崽。
- 接续锚点：听墙角实况 docx（"我去检查陷阱"＝听墙角借口变主线入口）。

## 四、早春出发

- **时序【2026-08-24 拍板】**：阿贝尔先告知丽希娅与赤红剑小队"**夏天回国**"（假时间表＝表层掩护：全队真心相信→行为自然呈夏天形状，敌人按夏天校准毒酒与伏兵）；**其后**内线密报送到——父王与王兄有中毒早期迹象，**只说家事，没说国事**。
- **对凉不避**：石板通信全程不躲着凉，解释到"家事"为止。凉的视角完全成立：有家事 → 名正言顺配合他早点回去。（RP 运营：凉侧一句 PR"之后阿贝尔用石板通信都没有躲着凉"即可，agent 不乱。）
- 痕迹（深夜借石板＋假夏天时间表）留给丽希娅日后复盘。
- 凉的说法只有一句：**"我只送你到出口。"**——不诡辩、不解释，把过山包装成护送：人一路走到出口，嘴上始终不承认自己过了山（与"只能把你送到山顶"同构；他清楚过山即影响压制、与路径无关，这句"送你"是怄的出口，不是豁免）。垭口全程没被踩脏，保住"专程告白地"。
- 凉的亲历前科【2026-08-24 拍板】：**5 年前他走过一次垭口，身体确实出了问题**——禁令对他是病历不是规矩，这次走山腹是带着病历进山。

## 五、山腹【2026-08-24 拍板：三关结构】

- **第一关＝师父早年设在山腹的魔偶点**：凉的**半成品集合体**（没烧完的草稿，缺龙血与完成的魂，想把自己写完）。**苦战**——凉重伤、身体部分**陶土化**，魔偶本体明确暴露给阿贝尔（W1 只有转述＋临终陶土，W2 阿贝尔亲眼确认，读者同此）。坟场两读【2026-08-24 订正】：凉不是自认可替换——他只是再次肉身确认问题长在自己身上，为龙墓里"自愿归还＝一劳永逸解决库尔之子"的点头垫底；阿贝尔读出"备件成不了他"。
- **第二关＝芬里尔白给放行带路**（三层不粘锅：还崽恩／王血误读／守墓归位）——两个地狱之间的一口喘气；师父的半成品想拆了他 vs 卢温的守墓人抬他过去。
- **第三关＝龙墓**：守墓人近道恰擦龙墓 → **误入卢温墓穴**（两人都不知道墓的位置，误入是诚实事故）。凉大限将至（容器在碎），为龙墓里再次点头埋下合理的账。
- 靠近龙墓时凉体内龙血躁动，如被本主隔空拽。（可选画面：换下的陶土残躯留在龙墓，卢温的墓里多一件藏品。）

## 六、龙墓交易

- 卢温半真半假报价：凉若**自愿**归还龙血，可"顺手把那个东西（库尔之子）带走"，结果不予说明。凉差点点头 → **阿贝尔一记手刀打晕凉**，抢先替他拒答。（后台口径【拍板 B 档】：报价为真。）
- **换装顺序（先接后松）**：血契成立（阿贝尔↔蛋，卢温公证）→ 库尔之子迁入龙蛋（**蛋＝成型但已死的龙胎**）**当场孵化——出壳即 W1 小龙形态，可直接变人形凉（带龙尾）；体型＝W1 小龙规格，比马大一点（未完成破壳的龙胎，不会巨大）【2026-08-24 拍板】；孵蛋期／小龙期全取消** → 归还龙血 → 卢温升天。
- **两次醒来与喂血定魂【2026-08-24 拍板】**：**第一次醒来＝小龙破壳瞬间**——刚出壳虚弱、意识模糊，很快又晕过去（凉的 POV 全程只剩碎片，不知交易）；**卢温此时仍在场**，教阿贝尔通过血契固定凉魂于龙躯的办法：**割自己的手，喂小龙血**；喂血后稳定，龙躯转入人形；**第二次醒来仍在龙墓**——凉发现自己已经龙变人，多了一条尾巴。物证暗扣：阿贝尔掌上的割伤是凉看得见的唯一现场遗迹。
- **价格：阿贝尔寿命减半；一人死则两人同死。** 契约是哑的（通生命状态，不通情绪思想）。
- **出厂重置·美白【拍板】**：森林十几年的晒黑、老茧、伤疤随旧躯壳清零，人形凉白得发光；凉出山打水照见才发现。
- 阿贝尔的供养资格＝还魂者履历（"你回来过。"）；价格揭晓＝掉马：凉第一次知道阿贝尔死过。
- **卢温藏条款**：真龙身体只是把大旱**改成慢性病**，要定期喂本源之水——签约时没说，事后才发现被阴了一手。
- 金手指：变龙能说话。

## 六之二、墓中问答·话术定稿【2026-08-24 亲妈拍板】

凉醒来三问，阿贝尔三答，语气顺序＝训—哄—收。三句零机制含量，全是态度和账本；王子不当王子用，当团长用。

1. **"你为什么打晕我？"** → **"你慷慨赴义的样子，我这个团长看过太多次了。不值得。"**（全真＋合法双关：表面＝赤红剑团长的公开履历，无辜读法成立；凉带 W1 档案听到的是"你看过我"——但追问即亮档案，问不出口。"不值得"＝全书主题暗桩：W1 没能说的话，W2 伪装成团长吐槽提前说出。手刀由此重新定性＝老兵的条件反射，不是知情者的拦截。）
2. **"怎么多了条尾巴？我现在是什么？"** → **"你运气不错，白捡了一个龙的身体。"**＋亮掌上的伤口："费了我不少血。"（赠予框架但字字目击证词：蛋是卢温给的、身体在墓里换的，他全程在场，零超纲知识。伤口从暗雷改收据——坦荡是最高级的封口：展示最小面额的支付（一点血），藏起最大面额（半条命）。）
3. **"代价呢？"** → **"一些代价。帮我回去解决点家事，就当还债了。"**（"一些代价"＝掉马日定时炸弹：同一句话两次结算，第二次连本带息。"还债"框架三重功能：给凉名正言顺的上车理由／与"内线报毒只说家事"同一口径／掉马日翻面——摆收债姿势的人才是欠债的。）

写法约束：凉的沉默＝他的伪装在替阿贝尔保管秘密（互演纪律没收审计权：问得越专业越暴露自己有对照组，只能问到"普通同伴"的深度）。RP 侧 agent 友好：团长腔嫌弃＋后怕，最难写崩的语气。

## 七、章末：王子亮牌【2026-08-24 亲妈拍板·第一章终点】

- 亮牌地点【2026-08-24】：不在出墓时揭晓——憋一路，憋到家门口。两人出龙墓后赶路回国，走到**卢恩王城的下水道暗门前**。
- 亮牌方式【2026-08-24 再改订】：**阿贝尔不自己曝**（此刻他估计有点"翘尾巴"——注意全书唯一的尾巴长在凉身上，阿贝尔只能精神翘尾）——让秘密联络的**内线亲自来接**，借别人的口：来人躬身——**"欢迎回来，阿贝尔殿下。"**
- 名号拆分：此处只露"殿下"。**"二王子"的名头和本名，留给亨利亲口说**【2026-08-24 拍板：归入叛乱篇糖醋线——弟弟的底牌由哥哥来翻，顺便配亨利的恶趣味】。
- 节拍：凉憋了一路问家事，阿贝尔乐得顺杆爬；内线这一躬身，替他把"我家"两个字说了。喜剧点不变：全书最隆重的身份宣告，发生在全书最不隆重的入口——王子回自己家，走的下水道。
- 互演层注记：凉早知道他是谁，验收的是他肯让人开口这件事本身；殿下之名借内线之口落地，比自报家门更像回家。
