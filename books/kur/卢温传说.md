# 古龙王卢温·传说层设定（第二版）

> 2026-08-29 按亲妈拍板前提重写：**传说中古龙王卢温陨落，血脉中诞生了现在的巨龙一族；师父依据这个传说找到卢温，借龙血创造魔偶。**
> 本档是**世界内传说**（角色听到的版本），不是设定真相。结构：各版本传说正文 → 师父的读法 → 误读对照表 → W2 使用点。
> 总原则不变：流传中丢掉系统层，留下灵魂层。

## 一、神殿正典版（王城/神殿口径）

太古之时，有龙王卢温，赤龙，躯长五十丈，群龙之先。
龙王与山争——争的什么，正典不载，一说为地水，一说为天规——战于魔山，**龙王陨，血浸群峰**。
其血渗入石脉水脉，化生巨龙一族，散于四方。故老相传：**龙非生，龙是化出来的。**
龙王之躯葬于山中，地名失传，唯童谣一句指路。
正典判词曰：「父死而族生。山川受血，至今未还清。」

## 二、民间火塘版（南境口头）

从前有一条最大的龙，跟大山打架，没打赢。
他的血顺着石头缝流下来，流到哪儿，哪儿就钻出小龙。
所以现在山里才有这许多飞龙、地龙、蠢龙。
老龙王没死透，在山里头睡着——睡够了要收账的。
他借出去的东西，从来都要还。

## 三、冒险者公会版（会规附件）

- 东山龙族不可招惹：不宣而战、不分青红皂白，血脉近古龙者智近人，勿以畜生视之。
- 魔山不设悬赏，"过山单"无一生还。
- 南境任务止于隆德森林北缘。
- 幸存者口述（仅两例，均不可靠）：雾里全是狼；狼会说话；狼说**没有遇见过你**。

## 四、帝国档案版（德布希情报部门残页）

巨龙一族军用的极限是双足飞龙（骑乘、驯化皆有成例）；其上古龙血脉，智性与力量均不可控，结论：勿动。古龙王的传说本身被列为"可能的真实资产"，墓址评估为"不可考"——他们找过，没找到。

## 五、儿歌版（隆德南北两岸童谣）

> 龙爷爷，打大山，没打赢，睡里边。
> 睡了千年不起来，血变小龙满山玩。
> 雪山高，雪山深，雪山里头有龙坟。
> 龙坟底下河水流，流到我们家门口。
> 莫进山，莫敲门，敲了门，问狼群。
> 狼说：没有这个人。

## 六、师父的读法（传说 → 坐标 → 配方）

师父是全大陆几百年来第一个**把儿歌当文档读**的人。三步：

1. **当坐标**："龙坟底下河水流"——逆龙骨河而上，水尽处即墓。（大概率在暮光之地档案馆拼出的这条线，跟她查"库尔"记载是同一套动作。）
2. **当配方**："血脉化生巨龙一族"——龙王的血有创生活性；造不出活魔偶的她读到的不是神话，是**下级借用说明书**：一滴古龙血，可以补完一具烧不成的容器。
3. **当合同预审**："他借出去的东西，从来都要还"——她带着卷宗上门，把"为什么借"押给了他。抵押物是账本。

## 七、误读对照表（传说条目 ⇄ 真事）

| 传说 | 真事 |
|---|---|
| 龙王与山争，陨落，血浸群峰 | 【真相待定】他与库尔同格；倾向：他活着时就在做"压制"的旧职，陨落与此职有关；借血给师父＝职务移交，不是新发明 |
| 血化生巨龙一族 | 他的血确有创生活性——师父据此借一滴血融入魔偶（凉体内那滴） |
| 睡了，睡够了要收账 | 残魂在墓中；借出的血归位即升天 |
| 龙坟底下河水流 | 龙墓泄水＝龙骨河水源地 |
| 狼说"没有这个人" | 芬里尔一系对空气念的假报告（"未曾遇见何人"） |
| 东山龙族不可惹 | 原典东山龙群（龙王旧属/远亲）设定 |

## 八、W2 使用点

1. **神庙壁画有了内容**：坠龙图——龙王与山争、陨落、血化为群龙。两人进庙读的是神话层，读者读的是真相层，双层阅读成立。阿贝尔可合法嘀咕："画得比他本人威风。"
2. **卢温对自己传说的反应**："本王什么时候输给过一座山？"——哇哈哈哈哈。正主对传说有意见，但不多。
3. **蛋的身份候选（建议）**：若巨龙一族皆出其血脉，墓中那颗死龙胎可以是**他一族最后一颗没孵出来的蛋**——陪葬即陪冢。给凉的身体＝龙王一族最后的后裔躯壳。这句话卢温永远不用说，读者自己会接上。
4. **借血的定性升级**：师父不是投机借血，是接续了一桩龙王活着时就在做的旧职（压制）。龙墓里卢温可以点这半句："她不是第一个来借的。是第一个带着账本来的。"
5. **升天后的新传说**："龙坟空了"／"那年龙骨河的水特别暖"——新传说的诞生现场写给读者看。
