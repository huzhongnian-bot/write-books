# 超现象管理局
一般简称为超管局。
以维系人类社会稳定存续为使命，处理异常现象，回收、管理超实体，隐身于现代社会的巨大组织。
在人类社会的阴影中占据主导地位。

# 泉莲集团
以南廷为中心的巨大金融集团。
其经营范围涵盖实体产业、资产管理、金融服务、财富管理等领域，实力雄厚。传言和地下势力有着不清不楚的联系。

# 和祥义
在南廷新近崛起的地下社团。
历史较短，以前来南廷务工的同乡会形式诞生。由于核心成员来自同一地区，内部非常团结，在街头以作风凶猛而著称。

# 全联堂
以南廷为中心，历史悠久的地下社团。
相传有上百年历史，影响力广大。在十几年前的街头战争中取得胜利，组建和领导了地下联盟。近年来随着时代变革，主动迎接转型。

# 收管
超管局收容和管理诸多超实体，以此保持着世界的平凡和稳定。
为了锁住千奇百怪的超实体，多种措施被研发，最终造就了遍布世界各地的独立站点。

# 超实体
一切有悖常理之物的统称。
小部分超实体随着科学发展而解明，更多超实体则显得愈发怪诞。常被人视作大灾难的前兆，或是通向未来的门径。

# 源数学
超管局主要技术路径之一。对多种古代秘传逆向工程而得的现代仪式系统，是以数学为工具符号，操作外界事物的技术。

# 奇媒体
超管局主要技术路径之一。以认知心理学和脑科学为基础，结合多种信息类超现象而得的异常符号理论。是操作心智、认知，于当代十分活跃的技术。

# 内工程学
超管局主要技术路径之一。汇总、优化了多种古代秘传后推陈出新，对自身进行操作的技术系统。由于其形式上的复古，被认为是最传统的主要路径。

# 方术
来源可疑的民间技术，对超实体有一定的干涉作用。
似乎是最近十年出现的新方法，内容大多是支离破碎的传统经文。由于极度杂糅，其真正原理难以解读。

# 重装者
运用超常技术的个人。
针对超现象和超实体事件，发展出了多种特殊技术。运用这些技术和衍生装备的个人即是重装者。这个概念通常用来与绑定者和受控者相区分。

# 绑定者
通过特殊程序，与超实体建立独特联系的个人。
绑定者通常会获得与超实体相关的奇特能力，也会令超实体状态趋向稳定。
与超实体的“适配性”是诞生绑定者的最大门槛。

# 受控者
被超实体效应支配的个人。
受控者的身体、心智通常会在不同程度上受到超实体干涉，这种干涉性一般意味着恶意或支配性。
大多数情况下，受控者应被视作危险。

# 绑定仪式
超管局在无数次试验后创造出的流程。
以极端手段迫使普通人类进入到现实剥离状态，并与超实体嵌合。因过程极其痛苦，即使在人才济济的超管局，也只有少量特工能完成该仪式。
一些民间同行组织经过长期积累，也总结出了自己的绑定方式。

# 寅字头
全联堂曾经的精锐小组。
多年前由彪骨统领，在地下战争中令南廷市诸多社团闻风丧胆，据说收纳了诸多奇人异士，各个有邪术护体，刀枪不入、不知疼痛，力大无穷。
在街头战争结束后逐渐淡出一般帮众视野，渐渐被人所遗忘。

# “传影”
南廷分局记载的资料中，全联堂持有一把代代相传的超实体古剑。
虽然其锋利能削金断玉，但缠有一股凶煞之气，因历任剑主均亡于非命而被定性为“邪剑”。\

# 南廷
历史悠久的沿海城市。
自古有名的港口城市，作为贸易枢纽有着上千年的历史。由于独特的地理位置，各个年代都是不同文化汇聚的商业重镇，人员和金钱的流动性极高。

# 泉莲大厦
泉莲集团兴建的地标性建筑，集团总部所在。
全高一百一十一层，创造了城市的最高点。据说占据了南廷新旧城区最好的风水。

# 雨塘大道
融合本地与外来的建筑风格，遍布骑楼的老式商业街。
已成为本地文化的一部分，完全融入了日常生活。近些年经常维修，似乎有被发展为人文景点的迹象。

# 和祥义据点
码头一带，仓储物流集中处。
和祥义发家于此，经营许久，已深植此地。时常能看见和祥义成员聚餐，当地人也习以为常。

# 十甫居茶楼
有着上百年历史的大型茶楼。
以特色茶点而闻名，历经百年风雨而屹立不倒。近年来被大型集团收购后逐步转型，目前品牌点心已分销至全国各地，各地分店规模也日渐扩展。

# 南廷分局据点
伪装成物流公司，外貌毫不起眼的建筑。
其占地广大，也开掘了巨型地下空间。在城市地铁规划中以地质不安全为由，绕开了这大块的空白区域。

# 黑房
位于泉莲大厦地下的秘密场所，疑似是全联堂举行绑定仪式的地点。
由重兵把守，无事时不建议靠近。

# 罗汉街
位于老城区，南廷历史最悠久的街道之一，被祖庙分割为了东街与西街两部分。
本地居民热情淳朴、相对守旧，在日常生活中仍体现着南廷的传统风貌。

# 祖庙
南廷最大的宗庙建筑群，人流与香火都极其旺盛。
以特色古戏台和百家祠堂闻名，祖传其中供奉着特殊的灵，但无人能说出其详细样貌。

# 涌泉中学 娱乐室
涌泉中学内部的娱乐室，一个能将学生们的幻想具象化的异常空间。在校园传说中是寄宿的学生们与“没有脸的家伙”交易而来。其中产生的异象会随着使用者接触的事物而改变。
因“灭麒麟”也染上了不可爱的桀桀怪笑，有学生要求把书架上的漫画与小说全部丢出去。

# 罗汉北街
祖庙附件的石板路小巷。相比热闹的祖庙和西街，这里更为僻静。全联堂的发祥地，忠义堂就坐落于此。

# 忠义堂（现）
忠义堂，曾经是南廷各帮会讲数的地方。泉莲崛起后，对此处进行了改建，当前风格偏华丽，多用于会客等目的。

# 忠义堂（旧）
多年前的忠义堂，曾经是南廷各帮会讲数的地方。不管在外面有多大的排场，在这都要对神仙恭恭敬敬。全联崛起，一家独大后，忠义堂逐渐衰落。

# 忠义堂前庭院
忠义堂前的小型中式庭院，院中的大树至少有两百年历史，在忠义堂最早建立的时代，这里也兼具演武场的功能。
