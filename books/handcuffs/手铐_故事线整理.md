# 《手铐》故事线整理（基于四段角色扮演素材）

## 一、时间线（已有素材的顺序）

**前史（隐形地基）：**
- 裘德截了马库斯一批劣质抑制剂的货，这批货又被凯抢走了一部分——三方恩怨闭环。
- **两人都不报警的原因**：裘德是黑户+灰色营生，报警等于自爆；凯自己染指走私劣质抑制剂/烟酒，派对带皮肉生意，同样见不了光。两个刚见面的仇人，各自见不得光，只能选择私了。

### 第一幕：手铐（家中）
1. 清晨宿醉醒来，两人被警用手铐铐在同一张床上。昨晚凯开派对喝断片；裘德昨晚十一点回救济所后被人从背后敲闷棍，醒来就在凯床上。
2. 互喷旧账：裘德骂凯"小三的儿子"，踩到凯的爆点；凯一肘子捣胃，警告"再提我妈打断你另一条腿"。
3. 打电话排除了室友Logan的作案嫌疑。
4. 凯扔了根蛋白棒给裘德，已过期两个月（Logan买的忘了）；裘德把咬过的蛋白棒吐到凯脸上。
5. 凯家的派对狼藉；凯称房子是自己租的，"我爸的钱我一分没要"。
6. 裘德在厨房抓面包吃，把整袋顺走，包装袋上留下脏指印。

### 第二幕：监控与保安室（汤普森太太家→保安室）
1. 凯拽着裘德去邻居汤普森太太家调监控（老太太标注了猫"露西"闹腾的时间段）。裘德用脏手抹脏凯的卡其色卫衣。
2. 监控显示：**凌晨1点12分，没开前灯的深色面包车停在凯家门口；一个穿连帽衫的人扛着裘德（带着口罩看不清脸），保安强尼用万能钥匙开凯家前门的**（上个月还帮凯家修过门锁）。
3. 打印截图揣兜。凯临走损卫衣："挺合身的，可惜你那一抹让它变抹布了。"
4. 保安室对峙强尼：凯分工"你来硬的，我来软的。别打死，死人不会说话"；出示截图逐条码罪名（非法入侵、绑架），然后把强尼"放"给裘德："去吧，裘德。这怂包归你了。"
   - **审讯补充**：强尼哭喊交代——当晚蒙面人**自称受马库斯指示，"给凯送一份大礼"**，给了足够多的封口费。强尼利欲熏心，加上很少有人知道自己和马库斯的关系，对方既然知道，想必是"自己人"——没多想就带路开锁了。**盲区由此成立：裘德凯早知道强尼和马库斯有一腿（臆断），强尼只知蒙面人一面之词（采信），三方凑成"铁证"，全员咬定是马库斯指使——而蒙面人到底是谁的人，没人知道。**
5. **裘德揍了强尼，抢走100刀当医疗费**——即第四幕药房买拐杖那卷钱的来历。
6. 此幕明确：凯是学法律的；两人达成"对付外人暂时搭伙，马库斯的事完了再算彼此的账"。

### 第三幕：钥匙（校园·咖啡厅）
1. 目标：找警用手铐通用钥匙。裘德提议找凯的前女友杰西卡（其父是警长）。
2. 咖啡厅被围观，流言四起；杰西卡当众发难。
3. 凯当众圆谎："社会心理学强制实验，研究人际冲突下的合作效率。"
4. 杰西卡给出钥匙，加码"下月论文帮我润色"；质问凯"分手说不想被绑住，现在倒愿意被铐着？"；临走骂裘德"跟他铐在一起不如跟条疯狗"，裘德报复偷偷顺走了钥匙。
5. 手铐解开。裘德没收手铐（"挂网上卖个好价"）；凯："手铐你留着，反正本来就是你的。"
6. 裘德嘴贱调戏杰西卡 → 凯揪衣领警告："再提她半个字，临时休战结束。"
7. 互殴旧账对质：裘德先拿板砖拍凯后脑（缝四针），凯踹断其脚踝（自称正当防卫）。

### 第四幕：饭（药房→超市→凯家）
1. 凯抽走裘德抢来的一百刀里的二十，买铝制拐杖。
2. 裘德主动要求做饭。
3. 超市：裘德亮手臂刀疤，自称"正经厨师班毕业，来钱太慢不想干了"。
4. 赌约：饭做砸→码头裘德先上；做好→凯"考虑以后少叫你跛脚猫"。
5. 裘德做了波龙意面、五分熟肋眼、无奶油土豆泥（知道凯健身不吃奶油）。
6. 餐桌交底：蓝带两年，主厨刀工课第一；"一天站十六小时被当孙子骂，不如干一票痛快"。
7. 凯："别再回救济所了。不是关心你——你欠我卫衣和咖啡，冻死了我找谁讨债。"
8. 凯夸"最会做饭的亡命徒"→ 触发裘德呕吐（PTSD发作，见人物卡）。
9. 凯的反应：把拐杖靠到水槽边、放矿泉水和姜汁汽水、把没吃完的意面封保鲜膜放进冰箱；嘴上骂"别吐第二次，通渠费很贵"；顺着裘德"牛排太油"的借口聊黄油。

### 第五幕：码头（踩点，夜）
1. 车上：凯给了裘德胃药，导航到码头区域。
2. 分工：凯上废弃塔吊，裘德守消防梯拐角。凯把折叠刀塞给裘德，工兵铲放在他够得到的地方，对讲机别上领口（频道三）。
3. 临别："你要是被发现，就按对讲机，我下来。今晚过后咱们两清，想骂我踹我都不还手。但在那之前，别死。"
4. 裘德点烟暴露位置，凯在对讲机里令其掐灭。
5. 发现：七号泊位，并没有交易，凯意识到可能已经被强尼出卖。
6. 【剧情断点】凯问裘德："你那边有没有看到什么？消防梯拐角能看到集装箱东侧的死角，我这边被吊臂挡住了。"

### 第五幕补完：码头之夜（定稿·侦察夜）

**前置：**
- 强尼向马库斯汇报"凯&裘德今晚要来搅局"（他本就是马库斯的线人，不算出卖，只是汇报）。马库斯加强巡逻，并把违禁品交易的位置和时间临时更换（货烫手、上线定了死时间，取消不了，只能在港区内部挪）。裘德和凯这边，本就打定主意要搅黄马库斯的局。
- **开局真相的盲区**：那晚是蒙面人自称受马库斯指示、花钱买通强尼带路开锁——马库斯本人是否知情、是否真是他指使，无人能证。裘德和凯早知道强尼和马库斯的关系（臆断），强尼只有蒙面人一面之词（采信），三方咬定马库斯。**袭击裘德的蒙面人是独立暗线，他自称的身份本身就可能是假的。**

**当夜流程：**
1. 裘德点烟暴露位置，马库斯加强后的巡逻队围向消防梯（**当晚码头只有马库斯的人**）。裘德被追得没路走，在对讲机里威胁/跪求凯下来帮忙。
2. 凯在塔吊上恰好从泊位变动中发现**交易换了新接头地点**——救人和取证两头烧，他把Logan的观鸟设备往支架上一架**开自动录像**，自己赶去救裘德。
3. **两人的骚乱逼马库斯的卖货交易再次临时挪窝**——走货的人手被抽去抓人，下水道走货口的井盖没来得及盖严。
4. 裘德跛着脚被追得走投无路，**一脚踩空掉进敞开的井盖**——下面正是马库斯的**下水道藏货点**：大货是铺天盖地的普通/劣质抑制剂，**违禁品混装其中、按盒记账、极稀缺**。头顶脚步轰鸣、手电光从井盖缝扫下来，他贴着管壁屏住呼吸；脚步远去后，借手机光翻到露头的医院专供包装，**顺手抄走两三盒**（口袋极限），一半想卖钱，一半自己断了药以为是高级货。
5. 下水道里没信号。裘德先拍好针剂特写素材，随后**当场试扎了一针**（穷到劣质抑制剂都用不起+发情期临近+不用白不用的心态）。**混装批次里这一针是违禁品还是劣质货，谁都说不准——薛定谔的针。**
   - **违禁抑制剂的真面目（都市传说）**：传说用了它能俘获心仪alpha的芳心——本质是先抑制发情期，再激化omega信息素紊乱，短时间内把omega的信息素改造成"目标alpha"喜欢的味道。SM夜店头牌商品。
   - **锚定机制**：改造的模板是注射后接触最密切的alpha信息素——裘德在下水道扎针时病急乱投医、无人在场，扎完针当夜就被凯用手铐铐着拴了一整夜，最密切的接触只有凯，**是手铐替他选中了凯**。
   - **药效三期**：①压制期（当夜，发情被压，感觉前所未有的顺）②反跳期（数小时后，信息素紊乱+嗜痛爆发，失控咬人）③改造期（随后数日，信息素向锚定味道漂移——凯开始觉得"这小子身上的味怎么有点好闻"的起点）。
   - **保质期**：改造只维持数周——传说的另一半："药效过了人家就不爱你了，所以得一直买"（灰市贩子的复购话术）。药效窗口内凯可以自欺欺人；**过了窗口他还在心动，错配揭晓**。
   - 裘德是卖了三年抑制剂的贩子，**听过这个传说**。扎完针得意时脑子里闪过"老子不会扎了那种玩意儿吧"——随即自我安慰"传说都是骗omega的智商税"，把疑虑按了下去。**双向误会就此成立：凯以为自己被药骗，裘德以为药根本没用。**
   - 素材里拍到了这批货也销往SM主题夜店，但裘德没注意到。
6. 凯一边引开追兵，一边寻找裘德时，意外翻进**B库房**——手机光扫到**成批的制式警察旧制服和配套手铐**：**保安公司的灰色副业**（承接退役制服装备回收，倒给灰市，与马库斯无关，只是库房同在港区），买家是SM主题夜店的"制服之夜"；**成套塑封里有一套被拆过，腰带环上空着——刚好缺一副**。凯记下夜店地址，拍了照，走人。 
7. 凯在地面找不到人，循着井口边的刮擦痕迹和**倒在井盖边的铝拐杖**把裘德从井里钓了上来（"你他妈怎么在下面""你他妈怎么才来"）。拐杖自此留在码头——物证。
8. 回到地面信号恢复，裘德**把针剂视频发进灰色生意小群显摆**（发完就撤，但已被人截图）——发送的瞬间远处传来追兵折返的动静。
9. 行动前，凯安排了Logan接应，Logan按指示取回设备，发现自动对焦全程锁定夜鹭、夜鹰、雨燕——**录了一晚上鸟类纪录片，交易证据为零**。但Logan狂喜。
10. 撤离与Logan汇合。药效进入反跳期（信息素紊乱+断崖反跳）叠上发情期激化的嗜痛症，裘德失控扑咬Logan。凯掏出裘德兜里那副手铐，把裘德和自己铐在一起，强行带回家——**手铐第二次启用：从刑具变成缰绳（也替他完成了锚定）。**
11. 到家后，凯翻到了裘德顺走的那两三盒针剂（裘德不知道他已看见）——凯拍照记录，东西原样留给了裘德：**"凯以为自己被药骗"的误会从此有了实物支点**，凯有了自己的私账和暗查动机。

**当夜结算（分开各自失败，合体刚好破案）：**
- 凯：握着手铐暗线的钥匙——制服手铐情报（缺一副+SM夜店地址）；外加一部夜鹭纪录片（交易证据为零）。
- 裘德：握着抑制剂线的赃物——两三盒针剂（用了一支；到家后被凯翻到拍照，东西原样留在裘德处，裘德不知情）、一条显摆视频（祸根）、体内一针"薛定谔的针"（若真，锚定=凯，保质期数周）。
- 马库斯：交易被搅了但没损失，只知道有人来闹过场。
- 回家路上两人对骂中一对信息，同时沉默——拼图完成。**两条线指向同一个地方：SM主题夜店（本市灰色集市枢纽，SM是皮、灰市是骨）——双人副本，各怀鬼胎还得装同心同德。**

**裘德夜店副本动机**：查清自己扎的那针（混装批次成分成谜）+ 显摆视频招来的追偿。
**凯夜店副本动机**：查那晚谁经手了这批货——"谁铐的"最后一步。
**马库斯的走货结构**：违禁品混装在普通/劣质抑制剂里，纯货极稀缺、按盒记账——裘德顺走的几盒里只要有真货，账立刻对不上，反扑动机拉满。
